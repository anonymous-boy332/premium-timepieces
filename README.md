# Ruiz Watch Store — Reference Design

A responsive HTML/CSS/JavaScript ecommerce front-end recreated from the supplied reference image.

## Files
- index.html — page structure
- style.css — responsive styling
- script.js — product rendering, tabs, search and cart counter

## Run
Open `index.html` in Chrome/Edge/Firefox.

The product photos use remote Unsplash image URLs, so internet access is needed for those images. You can replace them with local images later.
